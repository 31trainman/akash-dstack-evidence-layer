# Akash → dstack Unified Workload Verifier v0.9

This version implements the strict verification pipeline:

```text
evidence parsing
    ↓
hardware verification
    ↓
workload binding
    ↓
verified claims
    ↓
KMS policy
```

The KMS should never need to understand AMD or NVIDIA evidence formats. It should
consume only a `VerifiedWorkload` result.

## Security rules

A valid SNP report is not sufficient.
A valid GPU report is not sufficient.
Even both together are not sufficient.

They must bind to the **same**:

- fresh challenge / nonce;
- workload public key;
- immutable image digest;
- resolved config digest.

Any mismatch fails closed.

## Adversarial tests

v0.9 includes ugly-case tests for:

- old nonce;
- swapped public key;
- wrong config;
- bad REPORT_DATA;
- wrong GPU evidence;
- CPU evidence from one challenge + GPU evidence from another;
- missing GPU evidence when required;
- valid hardware with an unapproved image.

## Current mock boundary

The CPU/GPU hardware verifier classes in this package are test doubles. Replace
them with:

- v0.8 Trustee-backed real SEV-SNP verification;
- a Trustee/NVIDIA-backed GPU verifier.

The unified binding logic should remain unchanged.

## VerifiedWorkload contract

Successful verification returns only:

- challenge ID;
- nonce;
- workload public key;
- image digest;
- config digest;
- CPU/GPU verification booleans;
- normalized verified claims;
- workload commitment.

Everything else is rejected before KMS policy sees it.
